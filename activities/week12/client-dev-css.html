Client / Developer Team Project - All pages done

Every developer should have a good HTML structure for their client's site. This week you will be focusing on styling with CSS and focusing on the visual details.

This week's tasks:

  1. Client Tasks

    • Respond to any requests for more images or content from your developer, or any other questions they might have.
    • Look at the published page in the current HTML form and check that the content has been put in correctly with no typos.
    • Give your developer feedback as needed

  2. Lead Developer Tasks

    • Style the html with css to match the wireframe, colors, fonts and images and make it look nice.
    • Publish the changes to GitHub
    • Check the URL of site to see if the changes were applied
    • Let the client know the site has been updated and ask for feedback.
    • Correct the site according to any client feedback.
    • Once you have a good layout for the home page, begin the child pages for the site. Follow the wireframes for those child pages from your client's site plan. Use the same CSS style sheet for these pages.
    • Make sure all the navigation/menu links work between pages.

  3. Submit

    Submit the URL of the site you are developing.

    • Do Not submit a Live Server URL

    • Do Not submit a GitHub repository URL

    • Your link should look something like this:

    yourusername.github.io/wdd130/clientlastname/index.html


Project Overview

Each student will have 2 roles:

  1. Client: As a client, your are responsible for the site plan and content creation of your personal website. You will hire another student as your dev team to develop and code your site. You will communicate with the lead developer to make sure your site is completed on time.
  2. Lead Developer: As a lead developer you will be responsible creating the client's website. You will create the code for the home page of the client's site. You will then also code the two child pages. You will create and manage the GitHub repository where the client's website will be stored. Do not give the client access to the repository. You will be responsible for publishing the site online using GitHub pages. You will share the published website with the client on a regular basis.
